# Employee Management System

A Full Stack Employee Management System built using Spring Boot, React, and PostgreSQL with CRUD operations and REST API integration on employees.

---

## 🚀 Tech Stack

### Backend
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven

### Frontend
- React (Vite)
- Axios
- Bootstrap / CSS

---

## 📌 Features

- Add Employee
- Update Employee
- Delete Employee
- View All Employees
- RESTful API Integration
- Exception Handling
- Clean MVC Architecture

---

## 📂 Project Structure

employee-management-system  
│  
├── ems-backend (Spring Boot Application)  
└── ems-frontend (React Application)

---

## ⚙️ Backend Setup

1. Navigate to backend folder:
   cd ems-backend

2. Configure PostgreSQL in:
   src/main/resources/application.properties

3. Run the application:
   mvn spring-boot:run

Backend runs on:
https://ems-backend-0udc.onrender.com

---

## ⚙️ Frontend Setup

1. Navigate to frontend folder:
   cd ems-frontend

2. Install dependencies:
   npm install

3. Start the app:
   npm run dev

Frontend runs on:
https://employee-management-system-wnla.vercel.app/
